Interface and shutdown behavior:
  The default active-row path is CACHE_FILE.rowstate.  It can be overridden
  with --checkpoint-file FILE; the engine refuses a path that would overwrite
  the exact cache.  SIGINT and SIGTERM set only a sig_atomic_t flag.  The
  embedded exact recurrence polls at safe call boundaries and unwinds
  normally.  Main then atomically flushes completed exact fallbacks, writes
  FILE.tmp, verifies stream completion, and renames it over FILE.  A handled
  signal returns 128+signal; the deterministic test hook
  --stop-after-evaluations N returns 75.

  Startup automatically loads a compatible rowstate after the exact cache
  and all --base-record files.  It reports ROW-CHECKPOINT loaded, re-sweeps
  the active row from its first shape, and uses the restored row memo for work
  already completed.  The checkpoint is removed only after that row is
  complete.  A stale earlier rowstate is therefore safe after a killed write.

Version-1 state and validation:
  The binary file begins with magic SYLROW01 and format version 1 and ends
  with a 64-bit FNV-1a checksum.  It records:

    * base generators and derived f/tbar/window parameters;
    * active n and the last completed scan frontier;
    * every exact-cache key/outcome on which the saved state depends;
    * all even-part masks, lazy fill edges, gaps reconstructed from masks,
      first-P flags, and singleton-history frontiers;
    * every shape, offset vector, built transition specification, odd child,
      and even child;
    * complete outcome rings and value stamps;
    * the active-row memo, base P-hits, evaluation counter, and exact-work
      counters.

  Load requires identical generators and derived parameters and a current
  exact cache containing the recorded dependency set with identical values.
  It checks the checksum, count limits, base even part, addition closure,
  fill-edge closure, shape identity and references, ring dimensions and
  values, row-memo keys, and exact end of file.  Maps and derived indexes are
  rebuilt from the checked vectors.

Proof boundary:
  The local Brent comparison candidate is not serialized.  Resume begins a
  fresh exact-snapshot comparison sequence, which can only delay a period
  certificate.  It cannot manufacture one.  No outcome is inferred from the
  checkpoint, elapsed time, a signal, or a finite scan prefix.
