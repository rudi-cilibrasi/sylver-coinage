  Batch mode uses the largest exact Frobenius number in a stated finite range

  its own conductor, so sharing descendant memo states changes neither its
  legal moves nor the recurrence.  The differential tests compare this
  recurrence with the Python reference and independently rerun all accepted
  large P children.  No game precision cutoff is used; the memory limits only
  decide where a new batch must begin.
